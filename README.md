# Kellén Raimundo · Portfólio

Meu portfólio profissional, desenvolvido com **Next.js, React e TypeScript**, para apresentar minha trajetória como desenvolvedora backend, minhas habilidades e as tecnologias com as quais trabalho.

O conteúdo destaca minha experiência com Node.js, NestJS, APIs RESTful, microsserviços e integrações para Internet das Coisas (IoT).

## Sobre o projeto

O site reúne:

- Apresentação pessoal e áreas de atuação.
- Histórico profissional e formação acadêmica.
- Habilidades organizadas por especialidade.
- Download do currículo em PDF.
- Links de contato por e-mail e LinkedIn.

O layout utiliza fundo claro e detalhes em verde, com adaptação para celulares, tablets e computadores. Os parágrafos descritivos possuem alinhamento justificado e hifenização automática, conforme o suporte do navegador.

As ilustrações de arquitetura backend são construídas em CSS. A navegação inclui menu mobile, link para pular ao conteúdo e indicadores de foco para uso por teclado.

## Distribuição

- **Dados profissionais:** `src/data/profile.ts`.
- **Apresentação e seções:** `src/app/page.tsx`.
- **Cores, fontes e espaçamentos:** `src/app/globals.css`.
- **Título e descrição para buscadores:** `src/app/layout.tsx`.
- **Ícone do site:** `src/app/icon.svg`.
- **Currículo:** `public/curriculo-kellen-raimundo.pdf`.
